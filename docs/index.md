# LumenRAG

LumenRAG is a local-first retrieval-augmented generation (RAG) studio powered
by [LumenVec](https://github.com/brma-tech/lumenvec). It combines document
ingestion, vector retrieval, source-aware chat, and evaluation in a lightweight
web interface.

## Install

```bash
python -m pip install --upgrade lumenrag
lumenrag start
```

The PyPI wheels include the matching LumenVec engine for Windows, Linux, and
macOS. Configure an AI provider in the Studio or with environment variables.
